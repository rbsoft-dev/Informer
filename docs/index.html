Три шага

От запроса до уведомления на экране

Никакой настройки инфраструктуры — просто HTTP-запрос, который умеет отправить что угодно: 1С, cron-скрипт, кассовый драйвер.

01

Отправь POST-запрос

Обычный JSON на /api/notify — заголовок, текст, необязательный тип важности.

02

Уведомление появляется мгновенно

Всплывает в углу экрана. Несколько подряд — листаются стрелками, не перебивая друг друга.

03

Остаётся в истории

Полный список с фильтром по отправителю — ничего не теряется, даже если уведомление закрыли не глядя.

Возможности

Сделан для удобной работы

Одно окно уведомления, не башня окон

Новые сообщения не перебивают то, что вы уже читаете — листайте стрелками, когда будете готовы.

История с фильтром

Полный список уведомлений по отправителю, с отметкой прочитанного и удалением.

Свой язык без пересборки

Переводы — обычные текстовые .po-файлы. Новый язык скачивается прямо из Настроек.

API-ключ и анти-спам

Опциональная защита эндпоинта уведомлений и лимит запросов по IP из коробки.

Windows, Linux, macOS

Один и тот же процесс, self-contained сборка под каждую платформу — включая Apple Silicon.

Бесплатно и открыто

Лицензия MIT — используйте, меняйте, встраивайте в свои проекты без ограничений.

Интеграция

Работает с тем, что у вас уже есть

Любая система, способная отправить HTTP-запрос — 1С, PowerShell, Python, cron.

notify.sh 
curl -X POST http://127.0.0.1:4399/api/notify \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: ваш_ключ" \
  -d '{
    "header": "1С — Основная база",
    "description": "Новый документ проведён",
    "type": "info"
  }'
